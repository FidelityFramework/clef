# Representation range repair checkpoint

October 3, 2026. This checkpoint repairs the loss of range correspondence after
closure-environment, lazy and sequence representation rewrites. It does not
complete Phase B or native FFI acceptance.

Each rewriting nanopass maintains the finite-cell support it changes through
the representation recipe and its owning fold, following
[Baker Saturation Architecture §3](Baker_Saturation_Architecture.md). Renewal
retains stable obligation identity only when current graph evidence establishes
the same recurrence. Anchor retirement uses the shared implementation.
`NativeService` carries no premise snapshot or pipeline replay.

Generated frame reads derive fresh ranges from checked current storage and
source correspondence. Shared mutable captures retain logical cell identity,
including stores from write-only sequence owners. Unsupported writable borrows
and unaccounted closure/lazy stores withdraw range authority. Guard refinement
requires current source control, actual dispatch and storage correspondence,
and unbroken operand/comparison observations. Cached numeric ranges establish
none of those premises.

Numeric dependency accounts retain the typed control, capture, storage and
effect relations consumed by these readers. Tests include unchanged numeric
results with changed support and withdrawal of the earlier downstream proof.
The public Fidelity.PSG schema remains 16; callable aggregates and native ABI
settlement are subsequent work.
